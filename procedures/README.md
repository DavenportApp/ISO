## Overview

This directory contains the core operational procedures for our ISO 9001:2026 Quality Management System. These procedures provide detailed instructions for key QMS processes and ensure consistent implementation across the organization.

## Purpose

These procedures serve to:
- Define standardized processes for critical QMS activities
- Ensure compliance with ISO 9001:2026 requirements
- Provide practical guidance for personnel
- Facilitate training and competency development
- Support continuous improvement initiatives

## Using These Procedures

### For Employees
1. **Read and Understand**: Familiarize yourself with procedures relevant to your role
2. **Follow Consistently**: Apply procedures as written for consistency
3. **Suggest Improvements**: Provide feedback when procedures can be enhanced
4. **Maintain Records**: Complete required forms and maintain evidence

### For Managers
1. **Ensure Training**: Verify team members are trained on relevant procedures
2. **Monitor Compliance**: Observe adherence to procedures
3. **Review Regularly**: Participate in periodic procedure reviews
4. **Support Improvement**: Champion procedure updates and enhancements

### For Auditors
1. **Verify Implementation**: Check procedures are being followed
2. **Assess Effectiveness**: Evaluate if procedures achieve intended results
3. **Identify Gaps**: Note areas where procedures need enhancement
4. **Recommend Updates**: Suggest improvements based on audit findings

## Procedure Maintenance

### Review Cycle
- **Annual Review**: All procedures reviewed at least annually
- **Triggered Review**: When process changes, regulations update, or issues arise
- **Post-Audit Review**: Following internal or external audits
- **Continuous Improvement**: Ongoing optimization based on feedback

### Change Management
1. **Identify Need**: Process owner or employee identifies improvement opportunity
2. **Draft Changes**: Prepare updated procedure with track changes
3. **Review & Approve**: Quality Manager and affected stakeholders review
4. **Implement**: Update controlled copies and train affected personnel
5. **Verify**: Confirm implementation and effectiveness

### Version Control
- All procedures include version number, date, and change summary
- Previous versions archived for reference
- Change history maintained in document management system
