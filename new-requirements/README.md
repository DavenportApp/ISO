# README for New Requirements (ISO 9001:2026)

## Overview

This folder contains documentation for the **new and enhanced requirements** introduced in ISO 9001:2026. These requirements represent significant advancements in quality management, reflecting current global priorities and technological developments.

## ISO 9001:2026 Major Enhancements

ISO 9001:2026 builds upon the foundation of previous versions while introducing critical new requirements to address:

1. **Climate Change** - First time climate change is explicitly required
2. **Digital Transformation** - Recognition of digital technologies in QMS
3. **Sustainability** - Integration of environmental and social responsibility
4. **Quality Culture** - Enhanced emphasis on organizational culture
5. **Expanded Risk Management** - More comprehensive risk and opportunity management

## Common Questions

**Q: Are these requirements mandatory for ISO 9001:2026 certification?**  
A: Yes. Climate change consideration is explicitly mandatory. Digital and sustainability are integrated throughout the standard and necessary for full compliance.

**Q: Do we need to be carbon neutral to certify?**  
A: No. The requirement is to identify and address climate-related risks and opportunities, not to achieve specific carbon targets (though setting targets is recommended).

**Q: What if we don't have digital tools yet?**  
A: Start with the basics (digital document management) and build progressively. The standard recognizes different maturity levels.

**Q: Is sustainability the same as environmental management (ISO 14001)?**  
A: Related but broader. Sustainability includes environmental, social, and governance aspects. ISO 14001 integration is beneficial but not required.

**Q: How much will this cost to implement?**  
A: Varies widely by organization size and maturity. Many improvements can be low-cost (awareness, process optimization) while others require investment (technology, renewable energy).

**Q: Can small organizations meet these requirements?**  
A: Yes. Requirements scale to organization size and context. Small organizations can implement proportionate measures.

**Q: How long does implementation take?**  
A: Typical timeline is 6-18 months, depending on starting point and resources. Can be done in phases.
